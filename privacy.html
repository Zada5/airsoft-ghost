Privacy Policy — Airsoft Ghost Uploader

Last updated: 2026-10-04

This app uses Google OAuth with the following YouTube Data API and YouTube Analytics API scopes: youtube, youtube.upload, youtube.readonly, yt-analytics.readonly, yt-analytics-monetary.readonly — solely to upload videos to, manage, and read analytics for the owner's own channel.

OAuth tokens are stored only on the owner's local computer.

No data is sold, shared with third parties, or used for advertising.

The app does not collect data from any other users.

Access can be revoked at any time at myaccount.google.com/permissions.

The app's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

This app uses YouTube API Services. By using it, you agree to be bound by the YouTube Terms of Service and the Google Privacy Policy.
